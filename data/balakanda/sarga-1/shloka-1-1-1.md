## संस्कृत (Sanskrit)

### संहिता

```
तपःस्वाध्यायनिरतं तपस्वी वाग्विदां वरम् |  
नारदं परिपप्रच्छ वाल्मीकिर्मुनिपुङ्गवम् ||
```

### पदच्छेद

```
तपः + स्वाध्याय + निरतं, तपस्वी, वाक् + विदाम् + वरम्, नारदम् + परिपप्रच्छ, वाल्मीकिः + मुनि + पुङ्गवम्
```

### पदार्थ

- तपः — तपस् (शरीर-वाङ्-मनःसु संयमः)
- स्वाध्यायः — वेदाध्ययनम् 
- निरतम् — तत्र रतम्, तत्ते निरतम् 
- तपस्वी — तपसि रतः 
- वाग्विदाम् — वाचं विदन्ताम् 
- वरम् — श्रेष्ठम् 
- नारदम् — देवर्षिम् 
- परिपप्रच्छ — परि + प्रच्छ (लुङ् लकारः) 
- वाल्मीकिः — सः महर्षिः 
- मुनि — तपोनिष्ठाः मननशीलाः वा 
- पुङ्गवम् — श्रेष्ठम् 

### अन्वया

```
वाल्मीकिर्मुनिपुङ्गवम् तपःस्वाध्यायनिरतं तपस्वी वाग्विदां वरं नारदं परिपप्रच्छ।
```

### भावार्थ

```
मुनिपुङ्गवः वाल्मीकिः वाग्विदां वरं नारदं पृच्छति — "को न्वस्मिन् साम्प्रतं लोके गुणवान् कश्च वीर्यवान्..." इति। अयं श्लोकः रामायणस्य प्रथमश्लोकः। अत्र श्रोता (वाल्मीकिः) प्रवक्ता (नारदः) च उभौ अधिकारिणौ इति दर्शितम् — वाल्मीकेः श्रवणाधिकारः, नारदस्य उपदेशाधिकारः च। नारदेन उक्ता श्रीरामकथा एव अस्य महाकाव्यस्य बीजम्।
```

## ಕನ್ನಡ (Kannada)

### ಸಂಹಿತೆ

```
ತಪಃಸ್ವಾಧ್ಯಾಯನಿರತಂ ತಪಸ್ವೀ ವಾಗ್ವಿದಾಂ ವರಮ್ |  
ನಾರದಂ ಪರಿಪಪ್ರಚ್ಛ ವಾಲ್ಮೀಕಿರ್ಮುನಿಪುಙ್ಗವಮ್ ||
```

### ಪದಚ್ಛೇದ

```
ತಪಃ-ಸ್ವಾಧ್ಯಾಯ-ನಿರತಂ, ತಪಸ್ವೀ, ವಾಕ್-ವಿದಾಮ್-ವರಮ್, ನಾರದಮ್-ಪರಿಪಪ್ರಚ್ಛ, ವಾಲ್ಮೀಕಿಃ-ಮುನಿ-ಪುಙ್ಗವಮ್
```

### ಪದಾರ್ಥ

- ತಪಃ — ತಪಸ್ಸು, ಮನ-ವಚನ-ಕಾಯಗಳ ಸಂಯಮ
- ಸ್ವಾಧ್ಯಾಯ — ವೇದಗಳ ಅಧ್ಯಯನ, ಸ್ವ + ಅಧ್ಯಾಯ
- ನಿರತಂ — ನಿರಂತರ ತೊಡಗಿಸಿಕೊಂಡಿರುವ
- ತಪಸ್ವೀ — ತಪಸ್ಸಿನಲ್ಲಿ ನಿರತನಾದವ
- ವಾಗ್ವಿದಾಂ — ವಾಕ್ಕನ್ನು ಬಲ್ಲವರಲ್ಲಿ, ವಾಗ್ವಿದರಲ್ಲಿ
- ವರಮ್ — ಶ್ರೇಷ್ಠನಾದ
- ನಾರದಂ — ನಾರದನನ್ನು (ದೇವರ್ಷಿ)
- ಪರಿಪಪ್ರಚ್ಛ — ವಿಚಾರಿಸಿದ, ಪ್ರಶ್ನಿಸಿದ
- ವಾಲ್ಮೀಕಿಃ — ವಾಲ್ಮೀಕಿ ಮಹರ್ಷಿಗಳು
- ಮುನಿ — ಮುನಿಗಳ / ಋಷಿಗಳ
- ಪುಙ್ಗವಮ್ — ಶ್ರೇಷ್ಠ (ಎತ್ತಿನಂತೆ ಎದ್ದು ಕಾಣುವ ಶ್ರೇಷ್ಠ)

### ಅನ್ವಯ

```
ಮುನಿಗಳಲ್ಲಿ ಶ್ರೇಷ್ಠನಾದ ವಾಲ್ಮೀಕಿ ಮಹರ್ಷಿಗಳು, ತಪಸ್ಸು ಮತ್ತು ಸ್ವಾಧ್ಯಾಯದಲ್ಲಿ ನಿರತರಾದ ತಪಸ್ವಿಗಳಾಗಿ, ವಾಗ್ವಿದರಲ್ಲಿ ಶ್ರೇಷ್ಠರಾದ ನಾರದರನ್ನು ಪ್ರಶ್ನಿಸಿದರು.
```

### ಸಾರಾಂಶ

```
ವೇದಾಧ್ಯಯನ ಮತ್ತು ತಪಸ್ಸಿನಲ್ಲಿ ನಿರಂತರ ನಿರತರಾಗಿದ್ದ ಮುನಿಶ್ರೇಷ್ಠ ವಾಲ್ಮೀಕಿಯು, ವಾಕ್ಕಿನಲ್ಲಿ ಪರಿಣತರಾದ ನಾರದರನ್ನು — "ಈ ಲೋಕದಲ್ಲಿ ಈಗ ಗುಣವಂತರಾರು? ಧರ್ಮಜ್ಞರಾರು? ಪರಾಕ್ರಮಿಗಳಾರು?" ಎಂದು ವಿಚಾರಿಸಿದರು. ಈ ಪ್ರಶ್ನೆಗೆ ಉತ್ತರವಾಗಿ ನಾರದರು ಶ್ರೀರಾಮನ ಕಥೆಯನ್ನು ಹೇಳುತ್ತಾರೆ — ಇದೇ ವಾಲ್ಮೀಕಿ ರಾಮಾಯಣದ ಮೂಲ. ಈ ಶ್ಲೋಕ ಕೇಳುವವನ (ವಾಲ್ಮೀಕಿ) ಮತ್ತು ಹೇಳುವವನ (ನಾರದ) ಇಬ್ಬರ ಔನ್ನತ್ಯವನ್ನೂ ತೋರಿಸುತ್ತದೆ.
```

## English

```
tapaḥsvādhyāyanirataṃ tapasvī vāgvidāṃ varam |  
nāradaṃ paripapraccha vālmīkirmunipuṅgavam ||
```

OR

```
tapahsvadhyayaniratam tapasvi vagvidam varam |  
naradam paripapraccha valmikirmunipungavam ||
```

### Word By Word Meaning

- tapah - तपः - ತಪಃ = austerity
- svadhyaya - स्वाध्याय - ಸ್ವಾಧ್ಯಾಯ = self-study
- niratam - निरतं - ನಿರತಂ = engaged in
- tapasvi - तपस्वी - ತಪಸ್ವೀ = ascetic
- vak - वाक् - ವಾಕ್ = speech
- vidam - विदाम् - ವಿದಾಮ್ = of the wise
- varam - वरम् - ವರಮ್ = best
- naradam - नारदम् - ನಾರದಮ್ = Narada
- paripapraccha - परिपप्रच्छ - ಪರಿಪಪ್ರಚ್ಛ = asked
- valmikih - वाल्मीकिः - ವಾಲ್ಮೀಕಿಃ = Valmiki
- muni - मुनि - ಮುನಿ = sage
- pungavam - पुङ्गवम् - ಪುಙ್ಗವಮ್ = bull/chief

### Meaning

```
Valmiki, the preeminent of sages, who was devoted to penance and the study of the Vedas, approached Narada, the foremost of ascetics and the most eloquent among the wise, to ask him a question.

This verse introduces the opening of the Valmiki Ramayana, establishing the two central figures: Valmiki as the seeker of knowledge and Narada as the divine teacher. It sets the stage for the profound dialogue in which Narada will narrate the story of Rama to Valmiki, ultimately inspiring the sage to compose the epic poem.
```
