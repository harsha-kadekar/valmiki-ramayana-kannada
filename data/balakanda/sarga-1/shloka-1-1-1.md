## संस्कृत (Sanskrit)

### संहिता

```
तपःस्वाध्यायनिरतं तपस्वी वाग्विदां वरम् |  
नारदं परिपप्रच्छ वाल्मीकिर्मुनिपुङ्गवम् ||
```

### पदच्छेद

```
तपः + स्वाध्याय + निरतम् + तपस्वी + वाक् + विदाम् + वरम्, नारदम् + परिपप्रच्छ + वाल्मीकिः + मुनि + पुङ्गवम्
```

### पदार्थ

- तपः — तपस् (शरीर-वाङ्-मनःसु संयमः)
- स्वाध्याय — स्वाध्यायः (वेद-अध्ययनम्)
- निरतम् — निरतम् (लीनम्)
- तपस्वी — तपस्वी (तपः-आचरण-शीलः)
- वाक् — वाक् (वाच)
- विदाम् — विदाम् (विदुषाम्)
- वरम् — वरम् (उत्तमम्)
- नारदम् — नारदम् (ऋषेः नाम)
- परिपप्रच्छ — परिपप्रच्छ (पृष्टवान्)
- वाल्मीकिः — वाल्मीकिः (महाकवेः नाम)
- मुनि — मुनि (तपस्वी)
- पुङ्गवम् — पुङ्गवम् (श्रेष्ठम्)

### अन्वया

```
वाल्मीकिर्मुनिपुङ्गवः तपःस्वाध्यायनिरतं तपस्विनं वाग्विदां वरं नारदं परिपप्रच्छ
```

### भावार्थ

```
इदं रामायणस्य प्रथमं श्लोकम् अस्ति। मुनिश्रेष्ठः वाल्मीकिः तपस्यायां स्वाध्याये च निरतं तपोनिधिं वाग्मिनां श्रेष्ठं नारदं प्रश्नं पृष्टवान्। सः 'को न्वस्मिन् साम्प्रतं लोके...' इति प्रश्नम् आरभ्य धर्मस्य विषये पृच्छति।
```

## ಕನ್ನಡ (Kannada)

### ಸಂಹಿತೆ

```
ತಪಃಸ್ವಾಧ್ಯಾಯನಿರತಂ ತಪಸ್ವೀ ವಾಗ್ವಿದಾಂ ವರಮ್ |  
ನಾರದಂ ಪರಿಪಪ್ರಚ್ಛ ವಾಲ್ಮೀಕಿರ್ಮುನಿಪುಙ್ಗವಮ್ ||
```

### ಪದಚ್ಛೇದ

```
ತಪಃ-ಸ್ವಾಧ್ಯಾಯ-ನಿರತಮ್-ತಪಸ್ವೀ-ವಾಕ್-ವಿದಾಮ್-ವರಮ್, ನಾರದಮ್-ಪರಿಪಪ್ರಚ್ಛ-ವಾಲ್ಮೀಕಿಃ-ಮುನಿ-ಪುಙ್ಗವಮ್
```

### ಪದಾರ್ಥ

- ತಪಃ—ಧ್ಯಾನ, ವ್ರತ
- ಸ್ವಾಧ್ಯಾಯ—ವೇದ ಪಠಣ
- ನಿರತಂ—ನಿರಂತರವಾಗಿ ತೊಡಗಿರುವ
- ತಪಸ್ವಿ—ತಪಸ್ಸು ಮಾಡುವವನು
- ವಾಗ್ವಿದಾಂ—ಮಾತಿನ ವಿದ್ಯೆ ತಿಳಿದವರ
- ವರಾಮ್—ಶ್ರೇಷ್ಠ
- ನಾರದಂ—ನಾರದ ಮುನಿಯನ್ನು
- ಪರಿಪಪ್ರಚ್ಛ—ಸೂಕ್ಷ್ಮವಾಗಿ ಪ್ರಶ್ನಿಸಿದನು
- ವಾಲ್ಮೀಕಿಃ—ವಾಲ್ಮೀಕಿ
- ಮುನಿಪುಂಗವಮ್—ಮುನಿಗಳ ಶ್ರೇಷ್ಠ

### ಅನ್ವಯ

```
ತಪಃಸ್ವಾಧ್ಯಾಯನಿರತನಾದ ತಪಸ್ವಿಯೂ, ವಾಙ್ವಿದಾಂ ವರಾಮ್ ನಾರದಂ ಪರಿಪಪ್ರಚ್ಛ, ವಾಲ್ಮೀಕಿಃ ಮುನಿಪುಂಗವಮ್.
```

### ಸಾರಾಂಶ

```
ವಾಲ್ಮೀಕಿಯು ತಪಸ್ಸು ಮತ್ತು ವೇದ ಪಠಣದಲ್ಲಿ ನಿರತನಾದನು. ಆ ಸಮಯದಲ್ಲಿ ಅವನು ವಾಙ್ವಿದರ ಶ್ರೇಷ್ಠನಾದ ನಾರದ ಮುನಿಯನ್ನು ಭೇಟಿಯಾದನು. ವಾಲ್ಮೀಕಿಯು ನಾರದನನ್ನು ಏಕೆ ಮತ್ತು ಯಾವ ಉದ್ದೇಶದಿಂದ ಪ್ರಶ್ನಿಸಿದನು ಎಂಬುದನ್ನು ಈ ಶ್ಲೋಕವು ವಿವರಿಸುತ್ತದೆ.
```

## English

```
tapaḥsvādhyāyanirataṃ tapasvī vāgvidāṃ varam |  
nāradaṃ paripapraccha vālmīkirmunipuṅgavam ||
```

OR

```
tapahsvadhyayaniratam tapasvi vagvidam varam |  
naradam paripapraccha valmikirmunipungavam ||
```

### Word By Word Meaning

- tapah - तपः - ತಪಃ = austerity
- svadhyaya - स्वाध्याय - ಸ್ವಾಧ್ಯಾಯ = self-study
- niratam - निरतम् - ನಿರತಮ್ = engaged
- tapasvi - तपस्वी - ತಪಸ್ವೀ = ascetic
- vak - वाक् - ವಾಕ್ = speech
- vidam - विदाम् - ವಿದಾಮ್ = of the wise
- varam - वरम् - ವರಮ್ = best
- naradam - नारदम् - ನಾರದಮ್ = Narada
- paripapraccha - परिपप्रच्छ - ಪರಿಪಪ್ರಚ್ಛ = asked
- valmikih - वाल्मीकिः - ವಾಲ್ಮೀಕಿಃ = Valmiki
- muni - मुनि - ಮುನಿ = sage
- pungavam - पुङ्गवम् - ಪುಙ್ಗವಮ್ = chief

### Meaning

```
Valmiki, the foremost among sages, who was devoted to austerity and self-study, inquired of Narada, the best among those who know speech.
```
